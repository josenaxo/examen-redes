=== Etapa 3 - Seguridad basica y SSH (aplicado identico en ISP, R-Santiago, R-Valparaiso, R-Concepcion) ===
(Contrasenas reemplazadas por **** en este documento)

configure terminal
 no ip domain-lookup
 banner motd # ACCESO RESTRINGIDO: Solo personal autorizado - ApexLogistica SpA. Todo acceso es monitoreado y registrado. #
 enable secret ****
 service password-encryption
 username admin privilege 15 secret ****
 ip domain-name apexlogistica.local
 crypto key generate rsa general-keys modulus 1024
 ip ssh version 2
 line console 0
  login local
  exec-timeout 5 0
 line vty 0 4
  login local
  transport input ssh
  exec-timeout 5 0
 end
copy running-config startup-config
